## 🔄 Future Options

### Want to Use Red Hat Corporate Email Later?

When you get Red Hat SMTP settings from IT:

1. Edit configuration:
```bash
nano config/email_config.json
# Change sender_email to anareddy@redhat.com
# Update smtp_server to Red Hat SMTP
```

2. Update password:
```bash
export SMTP_PASSWORD="your-red-hat-password"
echo 'export SMTP_PASSWORD="your-red-hat-password"' >> ~/.zshrc
```

3. Reload LaunchAgent:
```bash
launchctl unload ~/Library/LaunchAgents/com.redhat.kernel.monthly.plist
launchctl load ~/Library/LaunchAgents/com.redhat.kernel.monthly.plist
```

### Want to Add More Recipients?

Edit `config/email_config.json`:
```json
{
  "recipient_email": "anareddy@redhat.com,team@redhat.com,manager@redhat.com"
}
```
